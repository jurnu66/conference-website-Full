# ตั้งค่าหลังบ้าน (Google Drive + Google Sheets)

หลังบ้านรันบน **Google Apps Script** ของบัญชี Google ของคุณ ไม่ต้องมีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย
แอดมินล็อกอินด้วย **อีเมล + รหัสผ่าน** ของระบบเอง ไม่ผูกกับ Google

| ส่วน | เก็บที่ไหน |
|---|---|
| ไฟล์บทความ PDF | โฟลเดอร์ Google Drive `CPE Seminar - Submissions` (ไฟล์ชื่อ `P-001 - ชื่อบทความ.pdf` วางตรงๆ ในโฟลเดอร์) |
| ข้อมูลบทความ, เวลาเปิด–ปิดรับ, รายชื่อแอดมิน | ชีต `CPE Seminar - Data` (แท็บ Submissions / Settings / Admins) |
| หน้าแอดมิน | `https://<เว็บของคุณ>/admin/` |

## 1) ติดตั้ง Apps Script

1. https://script.google.com → New project วางโค้ดจาก `backend/Code.gs` และ `appsscript.json` (เปิดแสดงไฟล์ manifest ที่ Project Settings)
2. เลือกฟังก์ชัน `setup` แล้ว Run (ครั้งแรกครั้งเดียว) จะสร้างโฟลเดอร์ + ชีต และเพิ่มอีเมลคุณเป็นแอดมินเจ้าของระบบ
   (ถ้าโปรเจกต์ใหม่ที่ไม่ได้รัน setup ให้เพิ่ม Script property `FOLDER_ID` และ `SHEET_ID` ชี้ไปที่โฟลเดอร์และชีตเดิม)
3. ตั้งรหัสผ่านเริ่มต้นของเจ้าของระบบ: Project Settings → Script properties → เพิ่ม
   `ADMIN_BOOTSTRAP_PASSWORD` = รหัสชั่วคราว (อย่างน้อย 8 ตัวอักษร)
   เมื่อล็อกอินครั้งแรก ระบบจะเก็บเป็นรหัสผ่านจริง (เก็บแบบแฮช) แล้วลบ property นี้ทิ้งเอง
4. Deploy → New deployment → Web app → Execute as: **Me** · Who has access: **Anyone** แล้วคัดลอก URL `/exec`

> แก้ `Code.gs` ภายหลังต้อง Deploy → Manage deployments → ✏ → เวอร์ชันใหม่ → Deploy (URL เดิม)

## 2) ใส่ค่าในเว็บ

แก้ `app/src/js/config.js` ใส่ `API_URL` แล้วรัน `npm run build` และอัปเดตเว็บ (RUN.md)

## 3) ใช้งานหน้าแอดมิน

เปิด `/admin/` ล็อกอินด้วยอีเมลเจ้าของระบบ + `ADMIN_BOOTSTRAP_PASSWORD`

- **งานที่ส่ง**: ปุ่ม **ซิงค์จาก Drive** สแกนโฟลเดอร์ Drive แล้วเพิ่ม PDF ที่มีคนวางลงโฟลเดอร์ตรงๆ เข้ารายการ (ชื่อบทความใช้ชื่อโฟลเดอร์/ไฟล์ ผู้เขียนใส่ภายหลังในชีต) และแจ้งรายการที่ไฟล์หายจาก Drive · ค้นหา กรองสถานะ ดาวน์โหลด PDF (ผ่านระบบ ไม่ต้องมีสิทธิ์ใน Drive) **ลบบทความ** (ย้ายไฟล์ไปถังขยะ Drive กู้คืนได้ 30 วัน) แก้สถานะ วัน เวลา ห้องนำเสนอ
- **เทมเพลต**: อัปโหลดเทมเพลต Word (.docx/.doc/.dotx) และ LaTeX (.zip/.tex) ผู้ใช้โหลดได้จากหน้าส่งบทความ อัปโหลดใหม่จะแทนที่ไฟล์เดิม ลบแล้วหน้าเว็บกลับไปแสดง "เร็ว ๆ นี้" (ไฟล์เก็บใน Drive ชื่อ `TEMPLATE_word_...` / `TEMPLATE_latex_...` ในโฟลเดอร์หลัก ไม่ต้องแชร์เป็นสาธารณะ)
- **กำหนดเวลา**: ตั้งเวลาเปิด/ปิดรับบทความ (ควบคุมฟอร์มจริง) ปุ่ม **เปิดรับตอนนี้ / ปิดรับตอนนี้** และวันแจ้งผล / ส่งฉบับสมบูรณ์ / วันจัดงาน (แสดงบนเว็บอัตโนมัติ)
- **แอดมิน**: เพิ่มแอดมิน (กรอกอีเมล + รหัสผ่านเริ่มต้น แล้วแจ้งเขาเอง) ลบแอดมิน เปลี่ยนรหัสผ่านตัวเอง และเจ้าของระบบกด "ตั้งรหัสใหม่" ให้คนอื่นได้ถ้าลืม

## แก้ไขเว็บไซต์ผ่านหน้าเว็บ (ข้อความ + รูปภาพ)

1. ล็อกอิน `/admin/` แล้วกดปุ่ม **แก้ไขเว็บไซต์** (มุมขวาบน) จะเปิดหน้าแรกของเว็บจริงพร้อมแถบเครื่องมือด้านล่าง
2. **แก้ข้อความ:** คลิกข้อความบนหน้าแล้วพิมพ์ · Enter = จบ · Esc = คืนค่าเดิมของข้อความนั้น · ปุ่มและหัวข้อพับ (เช่น FAQ) ดับเบิลคลิกเพื่อแก้ · แล้วกด **บันทึก** (ไทยกับอังกฤษแก้แยกกัน เปิดหน้า EN แก้ข้อความอังกฤษ)
3. **เปลี่ยนรูป:** กด **รูปภาพในหน้านี้** → เปลี่ยนรูป / คืนรูปเดิม (ระบบย่อรูปให้ไม่เกิน 1600px อัตโนมัติ รองรับ JPG PNG WebP GIF SVG)
4. เปลี่ยนหน้าด้วยเมนู "ไปหน้าอื่น" ในแถบเครื่องมือ (ลิงก์ในหน้าไม่พาออกตอนคลิก กด Cmd/Ctrl ค้างไว้ถ้าต้องการเปิดลิงก์) · **ออกจากโหมดแก้ไข** เมื่อเสร็จ
5. ข้อความในส่วนหัว/ท้ายเว็บ (เมนู แถบประกาศ ท้ายหน้า) แก้ครั้งเดียวมีผลทุกหน้า · รูปเดียวกันที่ใช้หลายที่ (เช่น โลโก้) เปลี่ยนครั้งเดียวมีผลทุกที่

การแก้ไขเก็บในชีตแท็บ `Content` ส่วนรูปที่อัปโหลดเก็บใน Drive ชื่อ `SITEIMG_...` ในโฟลเดอร์หลัก ผู้เข้าชมเห็นข้อความใหม่ภายใน 1 นาที (เบราว์เซอร์จำสำเนาไว้ ครั้งแรกที่เข้าอาจเห็นของเดิมแวบเดียวก่อนอัปเดต)

**แก้ไม่ได้ในโหมดนี้:** โครงสร้างหน้า (เพิ่ม/ลบ/ย้ายส่วนหรือรายการ เช่น เพิ่มกรรมการคนใหม่ เพิ่มแถวตารางกำหนดการ) · สีและฟอนต์ · ชื่อแท็บ/คำอธิบายที่ใช้กับเสิร์ชเอนจิน (title, description) · ข้อความ alt ของรูป · วันสำคัญ (แก้ในแท็บ กำหนดเวลา) — ส่วนนี้ต้องแก้ใน `conference-data.js` แล้ว build ใหม่

## ผู้ส่งบทความ: แจ้งสถานะ

- ส่งสำเร็จ → หน้าเว็บแสดง **ใบรับ** (รหัสบทความ ชื่อบทความ เวลาส่ง สถานะ) และส่งอีเมลยืนยันให้ ถ้าส่งอีเมลไม่ได้จะแจ้งในใบรับให้จดรหัสไว้
- ช่อง **ตรวจสอบสถานะบทความ** ใช้รหัสบทความ + อีเมลที่ใช้ส่ง ดูสถานะที่แอดมินตั้ง (รอพิจารณา / กำลังพิจารณา / รับ / ไม่รับ ...) และกำหนดนำเสนอ (วัน เวลา ห้อง) ไม่แสดงอีเมล ผู้เขียน หรือหมายเหตุของแอดมิน ใส่ผิด 10 ครั้งต่อรหัส ล็อก 15 นาที
- หน้าส่งบทความตรวจสถานะเปิด/ปิดรับใหม่ทุก 15 วินาที และทันทีเมื่อแอดมินกดบันทึก/เปิดรับตอนนี้/ปิดรับตอนนี้ (แท็บอื่นในเบราว์เซอร์เดียวกันอัปเดตทันที คนอื่นภายใน 15 วินาที) ถ้าผู้ใช้กำลังกรอกอยู่แล้วปิดรับ ข้อความที่พิมพ์ไม่หาย แต่ปุ่มส่งถูกปิด

## ความปลอดภัย / ข้อจำกัด

- รหัสผ่านเก็บเป็นแฮช (salt + SHA-256) ในแท็บ Admins คอลัมน์ `passHash` ห้ามแก้หรือลบด้วยมือ
- ผิดรหัส 5 ครั้งต่อ 1 อีเมล ล็อก 15 นาที · ล็อกอินค้างได้ 6 ชั่วโมงแล้วต้องเข้าใหม่
- ถ้าเจ้าของลืมรหัส: ลบค่าในช่อง `passHash` ของแถวตัวเองในแท็บ Admins แล้วตั้ง `ADMIN_BOOTSTRAP_PASSWORD` ใหม่
- PDF ไม่เกิน 10 MB (`MAX_BYTES`) · เวลาเป็นเวลาไทย (UTC+7) · โควตาอีเมล Apps Script ~100 ฉบับ/วัน

## ความเร็ว

- ระบบแคชรายชื่อแอดมิน ค่ากำหนดเวลา และเปิดชีตครั้งเดียวต่อคำขอ ล็อกอินครั้งเดียวได้ข้อมูลทั้งหน้าแอดมินกลับมาเลย
- ค่ากำหนดเวลาแคช 5 นาทีที่เซิร์ฟเวอร์ (ล้างทันทีเมื่อแอดมินบันทึก) และ 60 วินาทีในเบราว์เซอร์ผู้เข้าชม
- ครั้งแรกหลังไม่มีคนใช้สักพัก Apps Script จะ "ตื่น" ช้ากว่าปกติ 1–3 วินาที เป็นข้อจำกัดของ Google
