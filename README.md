# conference-website-Full

เว็บไซต์งานประชุมวิชาการ 300-1412 Seminar in CPE · CDTI พร้อมระบบรับบทความที่เก็บข้อมูลใน Google Drive / Google Sheets

- `app/` เว็บ (สร้างจาก `app/src/data/conference-data.js` ด้วย `npm run build`)
- `backend/` หลังบ้าน Google Apps Script (`Code.gs`) และวิธีติดตั้ง `SETUP.md`
- `RUN.md` วิธีรันและอัปเดตเว็บ · `DESIGN.md` กฎการออกแบบ

หน้าแอดมินอยู่ที่ `/admin/` (ล็อกอินด้วยอีเมล + รหัสผ่านของระบบ)
